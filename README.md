# Tools-Flipper-
Suite de 6 applications Flipper Zero (.fap) en C avec uFBT pour la formation à l’audit de sécurité : carnets de mission, journaux horodatés, checklists et export de rapports Markdown. Squelettes pédagogiques à compléter, sans acquisition matérielle active par défaut. Usage légal et autorisé uniquement.
